\# MySQL EDA Project



\## 📌 Project Overview



This project focuses on performing Exploratory Data Analysis (EDA) using MySQL.



The project uses SQL queries to explore, analyze, and understand the dataset. Various SQL techniques are used to identify patterns, trends, and useful insights from the data.



\## 🛠️ Tools Used



\- MySQL

\- MySQL Workbench

\- SQL



\## 🔍 Analysis Performed



The project includes:



\- Data exploration

\- Data cleaning

\- Handling NULL and missing values

\- Identifying duplicate records

\- Filtering and sorting data

\- Aggregate functions

\- GROUP BY and HAVING

\- SQL JOIN operations

\- Subqueries

\- Common Table Expressions (CTEs)

\- Window functions

\- Exploratory analysis using SQL



\## 📊 Key Skills Demonstrated



\- SQL Data Analysis

\- Data Cleaning

\- Exploratory Data Analysis

\- MySQL

\- Aggregation and Filtering

\- Joins

\- CTEs

\- Window Functions
